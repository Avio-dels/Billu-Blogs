# 🍃 Billu's Blogs

A Studio Ghibli-inspired blog web application — a gentle, immersive space for quiet stories and warm reflections.

## About

Billu's Blogs is built with a soft, nature-inspired aesthetic inspired by the calm beauty of Studio Ghibli films. Every design choice — from the animated cloud sky to the paper-like post cards — aims to create a peaceful, living world that encourages readers to slow down and engage thoughtfully.

## Design Principles

- **Soft, nature-inspired palette** — muted greens, sky blues, warm beiges, and sunlight tones
- **Organic, tactile UI** — components styled like paper notes and postcards with rounded edges and soft shadows
- **Gentle animations** — drifting clouds, floating leaves, slow parallax effects
- **Human typography** — Playfair Display serif headings + Lato body + Caveat handwritten accents
- **Warm navigation** — personal, exploratory language instead of corporate labels
- **Emotional warmth** — every interaction is designed to feel calm and inviting

## Pages

- **Home** — parallax sky scene with drifting clouds, featured stories
- **Stories** — full blog listing with category tags
- **Post** — clean, paper-white reading experience
- **About** — personal, warm introduction

## Tech Stack

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [React Router](https://reactrouter.com/) for navigation
- CSS custom properties for the design system
- Google Fonts: Playfair Display, Lato, Caveat
